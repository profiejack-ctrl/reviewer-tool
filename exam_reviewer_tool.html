🌐 Web Development Fundamentals & Architecture

Webpage Structure Technology

The technology responsible for providing the core structure and skeleton of a webpage is HTML (Hypertext Markup Language).

Key: HTML = Structure and skeleton of webpages

Primary Focus of CSS

In client-side frontend development, the primary focus of CSS is Styling, Layout, and visual design.

Key: CSS = Styling, layout, and visual presentation

Client-Side Interactivity Language

The client-side language used to implement behavior, interactivity, and dynamic logic on a page is JavaScript.

Key: JavaScript = Interactivity, behavior, and dynamic logic

Server-Side Database Management System

An example of a categorized server-side (backend) database management system is MySQL.

Key: Backend DBMS = MySQL

Role of an API

The role of an Application Programming Interface (API) is to act as a bridge or messenger that allows the frontend and backend to talk to each other.

Key: API = Bridge/messenger connecting frontend and backend

Web Data Transmission Protocol

The protocol referring to the rule sets used to securely transmit data across the web between the client and server is HTTPS.

Key: HTTPS = Data transmission rules protocol

Browser Rendering Process

The process of a web browser turning code into a viewable webpage is termed Rendering.

Key: Browser parsing code into UI = Rendering

Full-Stack Developer Definition

A Full-Stack Developer is best defined as a versatile engineer who can work on both the frontend (client-side) and backend (server-side) portions of an application.

Key: Full-Stack = Handles both Frontend + Backend

Iconic Text Editor

An iconic lightweight default text editor used for writing code is Notepad.

Key: Basic text editor tool = Notepad

Cross-Browser Consistency

A core part of a developer's job is ensuring a website works consistently across different Rendering Engines.

Key: Cross-browser compatibility = Across different rendering engines

HTML Acronym Definition

The acronym HTML stands specifically for Hypertext Markup Language.

Key: HTML = Hypertext Markup Language

Inventor of WWW and HTML

The visionary who invented the World Wide Web and introduced HTML is Tim Berners-Lee.

Key: Creator of WWW/HTML = Tim Berners-Lee

WWW Acronym

The acronym WWW stands for World Wide Web.

Key: WWW = World Wide Web

HTML Official Release Year

HTML was officially released in the year 1991.

Key: HTML Release Year = 1991

Interconnected Networks Infrastructure

A global group of interconnected computer networks combined with hardware and infrastructure is called the Internet.

Key: Interconnected networks = Internet

Rendering Engine Environment

An application containing a browser rendering engine capable of displaying web documents is Chrome.

Key: Browser containing rendering engine = Chrome

Static Website Concept

A type of website that displays fixed content and identical output every time a user visits is a Static Website.

Key: Fixed unchanging content = Static Website

Dynamic Website Concept

A type of website where content updates dynamically according to user behavior or interactions is a Dynamic Website.

Key: Interactive/changing content = Dynamic Website

ARPANET Acronym

The acronym ARPANET stands for Advanced Research Projects Agency Network.

Key: ARPANET = Advanced Research Projects Agency Network

Website Definition

A collection of related web pages grouped together under a single domain name and shared publicly on the Internet is known as a Website.

Key: Group of related pages under 1 domain = Website

🏷️ HTML Core Concepts, Elements & Structure

Meaning of "Hypertext"

The "Hypertext" portion of Hypertext Markup Language specifically refers to Hyperlinks that connect webpages to one another.

Key: Hypertext = Clickable hyperlinks connecting web pages

HTML Tag Definition

A command enclosed in angle brackets (< >) that specifies where an instruction starts and ends is defined as a Tag.

Key: Command in angle brackets < > = Tag

Complete HTML Element Example

A complete HTML element consists of an opening tag, content, and a closing tag, such as <p> This is paragraph </p>.

Key: Complete element = <p> Content </p>

HTML Attribute Identification

In the code snippet <a href="https://google.com">, the term "href" is classified as an Attribute.

Key: Extra specifier inside opening tag = Attribute

Empty Element (Void Tag)

An element explicitly classified as an empty element (void tag) that requires no closing tag is <img>.

Key: Void / self-closing tag = <img>

Root HTML Element

The tag that acts as the root element enclosing all other elements on the web page is <html>.

Key: Top root wrapper tag = <html>

Purpose of DOCTYPE Declaration

The primary purpose of the <!DOCTYPE html> declaration is to Tell the browser that the document is written in modern HTML5.

Key: <!DOCTYPE html> = Informs browser document is HTML5

Smallest Heading Tier

The heading tag that renders the structurally smallest heading tier is <h6>.

Key: Smallest heading = <h6> (Largest is <h1>)

HTML File Extension

When creating an HTML document source file on your computer, the required file extension is .html.

Key: HTML file extension = .html

VS Code HTML Boilerplate Shortcut

In Visual Studio Code, the shortcut character typed to auto-generate the basic HTML template is ! (Exclamation mark).

Key: VS Code HTML template shortcut = ! + Tab/Enter

📜 Text Formatting, Entities & Lists

Whitespace Collapsing Behavior

When multiple consecutive spaces in HTML source code are collapsed by browsers into a single space, it is called Blank Space collapsing.

Key: Multiple spaces collapsed into 1 space = Blank Space collapsing

Preserving Exact Whitespace

To preserve blank spaces and line breaks exactly as typed in your HTML code, you must use the <pre> tag.

Key: Preserves exact formatting & spaces = <pre> (Preformatted)

HTML Comment Syntax

The correct syntax for writing comments inside an HTML structure is <!-- comment -->.

Key: HTML comment = <!-- comment -->

Non-Breaking Space Entity

The special HTML character entity used to insert a non-breaking space on a webpage is &nbsp;.

Key: Non-breaking space = &nbsp;

Less-Than Symbol Entity

The HTML entity code used to safely render the less-than (<) character is &lt;.

Key: Less-than (<) symbol = &lt;

Registered Trademark Entity

To display a registered trademark symbol (®) on a webpage, you use the HTML entity code &reg;.

Key: Registered trademark (®) = &reg;

Text Highlighting Tag

The semantic tag specifically designed for visual highlighted text (yellow marker style) is <mark>.

Key: Highlighted text tag = <mark>

Description List Elements

The set of HTML tags utilized to construct a Description List consists of <dl>, <dt>, and <dd>.

Key: Description list set = <dl> (list), <dt> (term), <dd> (definition)

Lowercase Roman Numerals in Lists

When customizing an Ordered List (<ol>), setting type="i" changes numbering to lowercase Roman numerals.

Key: Lowercase Roman list numbering = type="i"

Purpose of the Start Attribute

The specific purpose of applying the start attribute to an ordered list is to change the starting numerical value of the list.

Key: <ol start="5"> = Changes starting number of list

📊 Tables, CSS & Styling Methods

HTML Table Caption Tag

The specific purpose of the <caption> tag in an HTML table is to add a title or descriptive caption to the table.

Key: <caption> = Adds table title

Merging Table Columns

The attribute used to merge table cells horizontally across multiple columns is colspan.

Key: Merge columns horizontally = colspan

Inline CSS Definition

The method that involves writing CSS rules directly inside an individual HTML tag's style attribute is Inline CSS.

Key: Style directly inside HTML tag = Inline CSS

CSS Acronym Definition

The acronym CSS stands for Cascading Style Sheet.

Key: CSS = Cascading Style Sheet

Standard Table Data Cell Tag

The HTML tag used to create a standard data cell in a table is <td>.

Key: Table data cell = <td>

Internal Element Spacing

To create space inside an element between its content and its border, you apply the CSS property padding.

Key: Space inside border = padding (Outside border = margin)

Internal CSS Placement

Internal CSS rules must be placed in the HTML document inside the <style> tag within the <head> section.

Key: Internal CSS location = <style> inside <head>

Merging Table Rows

The attribute used to make a table cell span multiple rows vertically is rowspan.

Key: Merge rows vertically = rowspan

Correct CSS Syntax Structure

The proper syntax format for writing CSS rules is SELECTOR { property: value }.

Key: CSS Syntax = SELECTOR { property: value }

Background Color CSS Property

The CSS property used to change the background color of an element is background-color.

Key: Background color property = background-color
